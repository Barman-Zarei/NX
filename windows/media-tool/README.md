# NX Media Tool (Windows 7 SP1+)
Target stack: Python 3.8 + PySide2 5.15.2.1 (Qt 5.15). `nxverify.py` is the tested core.
`gui.py` was tested headless on Linux (Python 3.8.20, PySide2 5.15.2.1) but never on Windows 7.
USB writing is NOT implemented. Linux alternative: `dd` or `cp` the hybrid ISO to the device (double-check the device name).
