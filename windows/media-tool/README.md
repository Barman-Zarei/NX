# NX Media Tool - LEGACY edition (Windows 7 SP1+)
Python 3.8 + PySide2 5.15.2.1 (Qt 5.15). `nxverify.py` is the tested core; `gui.py` was tested headless on Linux only, never on Windows. USB writing is NOT implemented.
See docs/compatibility/windows.md for the exact limits. Linux alternative: `sha256sum -c` and `dd`.
