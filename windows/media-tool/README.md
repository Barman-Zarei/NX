# NX Media Tool (mainline: Windows 10+)
PySide6 / Qt 6. `nxverify.py` is the tested core (pure stdlib); `gui.py` is tested headless on Linux only, never on Windows. USB writing is NOT implemented.
Windows 7 SP1+ is supported only by the `LEGACY` branch (Python 3.8 + PySide2). See docs/compatibility/windows.md.
